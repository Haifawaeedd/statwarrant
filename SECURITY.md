# Security policy

statwarrant is a small statistics library with no network access or stored credentials,
but it does parse text and numbers you give it. If you find a problem that could harm
users (for example code execution from crafted input, or a dependency issue), please
report it privately instead of opening a public issue:

* use GitHub's **Report a vulnerability** button on the repository's Security tab
  (private vulnerability reporting).

The maintainer aims to acknowledge reports within 14 days. Wrong statistical results
are not security issues; please report those as public bug reports so others can see them.

Only the latest development version is supported.
