# Code of conduct

statwarrant follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, specific and respectful. Disagreements about statistics are welcome;
personal attacks, harassment and discriminatory language are not.

To report unacceptable behaviour, contact the maintainer through GitHub (for example by
private vulnerability report if the matter is sensitive). Reports are handled
confidentially.
